# NTS Digital Solutions

Professional website for NTS Digital Solutions.

## Stack
React, Vite, Tailwind CSS, Framer Motion, React Router, React Hook Form, EmailJS.

## Local setup
1. Install Node.js 20+.
2. Run `npm install`.
3. Copy `.env.example` to `.env` and add your EmailJS values.
4. Run `npm run dev`.
5. Verify with `npm run build`.

## Deployment
Configure the `VITE_EMAILJS_SERVICE_ID`, `VITE_EMAILJS_TEMPLATE_ID`, and `VITE_EMAILJS_PUBLIC_KEY` environment variables in Vercel or your hosting platform.
